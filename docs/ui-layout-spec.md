# 工坊 UI 布局规范 v1（表格线分区 + 等大控件）

> 目标：**一眼能看出边界，一手能点中目标**。所有页面按本规范套用，不再各写一套间距和按钮。
> 配色/字体不变（暖纸底 + 墨字 + 绛红；全站 FangXinShu）。

---

## 1. 两条硬规则

**R1 分区靠线，不靠留白/颜色。**
每个区域的边界都是一条 `1px solid var(--line)`。区域内部不再用卡片套卡片来制造层次；需要分区就加线。
页面最小结构 = `顶栏 | 内容`；工作台 = `侧栏 | 标签栏 | 编辑区 | 底部面板`，任意两块之间必有一条线。

**R2 可点即等大。**
同一行 / 同一容器里，所有可点元素**高度相同**，图标按钮**宽度=高度**。
只有两档尺寸，且同一行只能用同一档：

| Token | 值 | 用途 |
|---|---|---|
| `--ctrl-h` | 36px | 页面主操作、表单、顶栏导航、标签栏 |
| `--ctrl-h-sm` | 32px | 密集工具条、侧栏/表格行内操作 |

禁止出现：无边框无底色的可点文字（按钮必须有描边或填充）、<32px 的点击目标、同一行混用两档高度。

---

## 2. 栅格与间距

- 间距只用 6 档：`4 / 8 / 12 / 16 / 24 / 32`（`--sp-1..6`）。
- 区域内边距默认 `12`（`--sp-3`）；页面内容左右 `16–24`。
- 行高：列表行 `36`；表格行 `40`；说明文字 `1.6`。

## 3. 字号（只用 5 档）

| Token | 值 | 用途 |
|---|---|---|
| `--text-xs` | 12 | 元信息、表头、徽标 |
| `--text-sm` | 13 | 正文、控件 |
| `--text-lg` | 15 | 卡片/区块标题 |
| `--text-xl` | 20 | 页面分块标题 |
| `--text-title` | 26 | 页面主标题（衬线） |

## 4. 组件尺寸（唯一口径）

| 组件 | 尺寸 |
|---|---|
| Button（默认） | 高 36、左右内距 12、圆角 8 |
| Button（小） | 高 32、左右内距 8、圆角 6 |
| IconButton | 36×36 / 32×32 |
| Input / Select / Textarea | 高 36（多行最小 36）、内距 8 |
| Segmented | 容器高 36（小号 32），item 撑满内高 |
| Tabs（页签/标签页） | 行高 36 |
| Badge | 高 20 |
| 表格 | 表头 36、行 40，列之间不加竖线（只加行线） |

## 5. 分区图

### 5.1 展示页（`/`、`/p/:code`、`/buffs`、`/substats`、`/me`、`/upload`）
```
┌───────────────────────────────────────────┐
│ 顶栏（36 高导航，统一描边）                 │
├───────────────────────────────────────────┤
│ 标题区：标题 / 一句说明 / 右侧主操作        │
├───────────────────────────────────────────┤
│ 内容列（表格或卡片网格）      │ 右栏（可选）│
└───────────────────────────────────────────┘
```
- 标题区与内容区之间一条线；右栏与内容列之间一条线。
- 一屏只允许一个主按钮（primary），其余为描边按钮。

### 5.2 工作台（`/edit/*`、`/lab/*`、`/admin/*`）
```
┌────┬──────────┬──────────────────────────────┐
│活动│ 侧栏      │ 标签栏（标签 + 右侧工具）      │
│栏  │（对象列表）├──────────────────────────────┤
│    │          │ 编辑区（一次只显示一个对象）   │
│    │          ├──────────────────────────────┤
│    │          │ 底部面板（输出，可折叠）        │
└────┴──────────┴──────────────────────────────┘
```
- 活动栏 52、侧栏 256、底部面板 144（默认收起）。
- 低频操作（快照/批处理/输出）统一进标签栏右侧的 `⋯` 弹出面板，不并排堆在标签行里。

### 5.3 编辑器（工作台内的编辑区）
固定三段，禁止交叉：
```
① 对象头   [类型徽章] 名称 ………………………… [状态徽章]
──────────────────────────────────────────────
② 列表区   左：对象内条目列表（行高 36）
   编辑区   右：当前条目字段
──────────────────────────────────────────────
③ 操作条   [状态文字] …………………… [⋯ 更多] [保存]
```
- 字段一律「label 上、控件下」竖排，label 12px 灰；同一表单内控件等宽。
- 长文本（如 folder 原文）用 Textarea（2–4 行），**不要塞进单行 input**。
- 状态只有四种：已保存 / 有未保存 / 保存中 / 保存失败，写在操作条左侧。

## 6. 表格规范

- 只画横线（行与行、表头下），不画竖线，不用斑马纹。
- 列对齐：文字左对齐、数字右对齐（`tabular-nums`）。
- 行内操作：**最多两个**描边小按钮；其余进行尾 `⋯` 菜单。
- 空态：一句话 + 一个主操作，居中放在表体区域。

## 7. 自查清单（每页提交前逐条过）

1. 每个可点元素都有描边或填充吗？高度是否与同行为同一档？
2. 区域之间是否都有 1px 线？有没有靠「卡片套卡片」表达层次？
3. 有没有 <32px 的点击目标？图标按钮是否正方形？
4. 一行里是否出现两种高度（如 28 的徽标旁放 36 的按钮）？
5. 表格里一行内操作是否 ≤2 个按钮？
6. 长文本是否都有多行控件？有没有把 60 字塞进单行输入？
7. 主按钮是否唯一？删除类操作是否在 `⋯` 菜单里？
